# Outreach: the people who write "AdSense alternatives" and "ad plugins for WordPress" lists

Found by web search on 14 Nov 2026. The lists change often; check each page is still live before writing. No contact
details are copied here: each site has its own contact page or "suggest a tool" form, and a few take guest posts.

## Who to write to first

Independent WordPress and blogging publications. They review tools for their readers and add new ones when updating a
list. Ask to be considered for the **next update** of the article, not for a link.

## Not worth writing to

These lists are written by ad companies that compete with VisionForgeX (they rank themselves first): MonetizeMore,
Clickio, Newor Media, Snigel, Sevio, EZmob, Adsterra. Useful to read for what publishers ask, not for outreach.
Advanced Ads' own list of [recommended ad networks](https://wpadvancedads.com/recommended-ad-networks/) is a plugin
maker's list; they sometimes add networks that integrate with them, so it is a later conversation, not a first one.

## When to send

After the plugin is live on WordPress.org with a few reviews (writers check the page first), and not more than a few a
week, so every reply gets a quick answer. Keep a simple list: site, date written, answer, date of their update.
